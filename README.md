# Fund Me API

Fund me is platform for everyone to fund a startup (especially in Indonesia) and grow together

## Overview

`fund-me-api` is maintained as part of Andriawan's personal project portfolio. The repository contains the source code, configuration, and supporting files for the project described above.

## Getting Started

Download dependencies and run the project:

```bash
go mod download
go run .
```
